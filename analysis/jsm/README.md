## 2. 점수 분해 식 (리더보드 해석의 핵심)

테스트 x는 0~12에 고르게 퍼져 있어 약 80%가 범위 안(x ≤ 10), 약 20%가 외삽 구간(10 < x ≤ 12)이다. RMSE²(=MSE)는 행 비율로 가중한 평균이므로

```
전체 MSE = 0.8 × A + 0.2 × E
  A = 범위 안 MSE,  E = 외삽 구간 MSE
  A ≥ σ² = 0.2² = 0.04   (노이즈 하한, 3절)
```

### 2-1. 한 제출에서 외삽 오차 상한 구하기

```
E ≤ (RMSE² − 0.8 × 0.04) / 0.2
```

예: 6조 0.24 → 0.24² = 0.0576 → E ≤ (0.0576 − 0.032)/0.2 = 0.128 → **외삽 RMSE ≤ 0.36**.
E 안에도 노이즈 σ² = 0.04가 들어 있으므로, 곡선 자체의 오차는 √(0.128 − 0.04) ≈ **0.30 이하**다.
"상한"인 이유: 범위 안을 하한(0.2)으로 맞혔다고 가정한 경우가 외삽 몫이 가장 크다. 범위 안이 더 나쁘면 E는 더 작다.

### 2-2. 두 제출 비교 (A 가정이 필요 없음)

x ≤ 10 예측이 비트 단위로 같은 두 제출이면 A가 같으므로 소거된다.

```
RMSE₁² − RMSE₂² = 0.2 × (E₁ − E₂)
```

예: up 1.40438, flat 0.88862 → (1.9723 − 0.7896)/0.2 = **E_up − E_flat = 5.91**.
그래서 probing을 할 때는 x ≤ 10 예측을 고정해 두어야 한다.

### 2-3. 한계

- Public은 테스트의 약 절반(약 5,000행)이고 그중 외삽 행은 약 1,000개다. 외삽 비율 0.2는 표본마다 ±0.006 정도 흔들린다.
- A = 0.04는 가정이다. 범위 안 Public 오차가 정확히 하한이라는 보장은 없다.

## 3. 노이즈 하한 σ ≈ 0.20

두 가지 방법이 같은 값을 준다 (`plot_train.py`).

1. **이웃 차분 (모델 가정 없음)**: x로 정렬한 이웃 두 점의 y 차이는
   `y_{i+1} − y_i = [f(x_{i+1}) − f(x_i)] + (ε_{i+1} − ε_i)`.
   x 간격이 평균 0.0002라서 첫 항은 거의 0이고, 독립 노이즈 둘의 차이 분산은 σ² + σ² = 2σ²다.
   → σ = √(mean(차분²)/2) = **0.2008**
2. **20차 최소제곱 잔차 표준편차**: **0.2003**

`analysis/overview` 브랜치의 결론(등분산 가우스 σ ≈ 0.2)과 일치한다. 진짜 f를 알아도 RMSE는 약 0.2가 남는다.

## 4. 왜 고차 다항식은 끝과 범위 밖에서 흔들리나

최소제곱 예측값은 모든 y의 가중합이라서 노이즈에 따른 분산을 계산할 수 있다.

- 직선: `Var(ŷ(x)) = σ²[1/N + (x − x̄)²/Σ(xᵢ − x̄)²]`. 기울기 오차는 중심을 축으로 시소처럼 돌기 때문에 끝이 가장 크게 움직인다.
- M차 다항식: 흔들림 방향(모드)이 M개로 늘어나고, Legendre Pₖ가 모두 끝점에서 크기 1로 최대여서 끝에서 오차가 겹친다.

| 20차, N = 50,000 | 이론 | 실측 |
|---|---|---|
| 끝점 x = 0, 10 | σ(M+1)/√N = 0.0188 | 0.019 |
| 가운데 x = 5 | ≈ σ√(0.64(M+1)/N) = 0.0033 | 0.0033 |

범위 밖에서는 이 증폭이 폭주한다. 20차 최소제곱 곡선의 f(12)는 −6,684였다. 이것이 Runge 현상(강의 4장)의 최소제곱판이다.
20차 곡선의 9.93 변곡점은 이 끝단 불안정성의 산물일 가능성이 높다. 0~1 부근 극점은 원인이 다르다. 0.2 단위 구간 평균이 −3.46 → −3.45로 변화가 0.02 이내인 평평한 구간이라서 f′ ≈ 0이고, 그래서 아주 작은 굴곡만 있어도 극점이 생긴다.

## 5. 범위 안은 이미 해결됨 (`inrange_methods.py`)

| 방법 (분석용) | 5-fold CV RMSE | f(10), f(11), f(12) |
|---|---|---|
| 20차 Legendre 최소제곱 | 0.2003 | −2.1, −159, −6,684 |
| 구간별 3차 (변곡점 9구간, 정규방정식) | 0.2007 | −2.1, 0.1, 12.7 |
| smoothing spline | 0.2006 | −2.1, 478, 3,493 |
| kNN (k = 200) | 0.2008 | −2.1, −2.1, −2.1 |
| gradient boosting | 0.2023 | −2.1, −2.1, −2.1 |
| MLP 64×64 tanh | 0.2045 | −2.1, −2.4, −2.2 |

- 범위 안은 어떤 방법이든 노이즈 하한에 붙는다. **순위는 외삽 구간 20%가 결정한다.**
- 범위 안 점수가 같은 모델들도 f(12)는 −6,684에서 3,493까지 갈린다. 외삽은 데이터에 정보가 없는 문제다.
- 500개 무작위 샘플로 정규방정식을 푼 초기값의 전체 데이터 RMSE는 20차 0.205, 구간별 3차 0.209다(최적 0.200). 과제가 말한 "500개 샘플 초기값 → 전체 데이터 최적화" 흐름이 잘 작동한다.
- 미분 추정(그림 아래 칸): 원자료 이웃 차분은 노이즈를 h ≈ 0.0002로 나누는 셈이라 표준편차가 약 10⁴로 쓸 수 없다. 0.25 구간 평균의 차분은 매끄럽다(강의 5장, 절단오차와 노이즈의 트레이드오프). spline 미분은 x = 10 끝에서 +2.8로 튀는 경계 인공물이 생긴다.

## 6. 모의 외삽 검증 (`mock_extrapolation.py`)

x < c 데이터만으로 학습하고 [c, c+h]를 예측한다. 기준점 c를 굴려 가며 평균을 낸다(rolling origin).
**h는 x 단위 길이**다. h = 2는 실제 과제의 10 → 12와 같은 폭이다. RMSE에는 노이즈 0.2가 포함된다.

| 방법 | h = 2 평균 (c = 6, 6.5, 7, 7.5, 8) | h = 1 평균 (c = 7, 7.5, 8, 8.5, 9) |
|---|---:|---:|
| 감쇠 직선 (끝 0.3 창 기울기, k = 1.0) | **1.51** | 0.80 |
| 감쇠 직선 (k = 0.5) | 1.70 | **0.79** |
| 수평 (끝 0.3 평균) | 1.51 | 1.25 |
| 직선 (창 0.3 / 0.5 / 1.0) | 2.09 / 2.15 / 2.17 | 0.79 / 0.87 / 1.26 |
| 2차 (창 1 / 2) | 4.54 / 4.55 | 1.57 / 2.03 |
| 전체 범위 Legendre 5 / 8 / 12 / 20차 | 15.6 / 175 / 416 / 3.4×10⁵ | 2.6 / 17 / 43 / 314 |

감쇠 직선: `y = a + b·(1 − e^{−k(x−c)})/k`. 끝 기울기 b로 출발하되 기울기가 점점 줄어드는 형태다(강의 8장 지수·포화 모델 계열).

해석:
- **차수가 낮을수록 외삽이 안정적이다**: 감쇠 직선 ≥ 직선 ≫ 2차 ≫ 고차. 7절 문헌(Demanet & Townsend)의 결론과 같다.
- train 내부에서 2칸 외삽의 최선값이 약 1.5인데, 6조는 실제 10~12에서 0.36 이하(2-1절)다. **실제 외삽 구간은 train 안의 물결보다 단순할 가능성이 높다.**
- 그래서 모의 검증은 외삽 **방법의 순위**를 정하는 근거로 쓰고, 오차 크기 예측에는 쓰지 않는다. 기준점마다 편차가 크다는 한계도 있다.

오른쪽 끝 추세 (0.1 단위 구간 평균의 기울기): 9.2 부근 −4.2 → 9.9 부근 −2.1로 하강이 완만해진다(f″ > 0).
직선 창으로 구한 기울기는 창 0.3 / 0.5 / 0.7 / 1.0에서 −2.18 / −2.68 / −3.10 / −3.49다. 2차 창의 f(12)는 −1.4~4.4로 창 폭에 민감하다.

## 8. 외삽 전략 제안 (팀 합의 전)

1. 범위 안 모델(구간별 3차 + Adam)은 고정한다. 그래야 2-2절 비교식을 쓸 수 있다.
2. 외삽 후보는 모두 "형태 선택 → 오른쪽 끝 창 데이터로 우리 최적화기로 학습"으로 만든다.
   - ① 학습한 직선 (창 0.3)
   - ② 감쇠 직선 `a + b·(1 − e^{−k(x−10)})/k` (a, b, k 모두 학습)
   - ③ 다른 창 폭의 직선 (창 폭은 모의 검증으로 결정)
   - ✕ 2차·3차 연장은 실패 사례로 보고서에 쓴다.
3. 제출 하나에 후보 하나를 내고, 계수를 바꿔 가며 재제출하지 않는다(규칙 위반 소지).
4. 12/03 최종 후보 2개: Public이 가장 좋은 형태와 근거가 가장 탄탄한 형태.
